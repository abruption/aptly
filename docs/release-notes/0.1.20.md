# Aptly 0.1.20

## 변경 사항

- 한국어·영어·일본어·중국어 간체 가이드의 설치, 자동 추천, 통계 설명을 다듬었습니다. 필요한 조건과 실행할 명령을 쉽게 찾을 수 있도록 문단을 나누고, 현재 읽는 언어를 표시하는 방식도 통일했습니다.
- 예산 안내에서 Decisions API 호출에 비용이 발생할 수 있는 시점을 설명하고, 로컬 요청 기록 파일에 어떤 정보가 저장되는지 명확히 했습니다. 일부 이전 버전의 릴리즈 노트에 빠져 있던 npm·소스 링크를 추가했습니다. [이슈 #199](https://github.com/abruption/aptly/issues/199) · [PR #200](https://github.com/abruption/aptly/pull/200)

## Windows 검증 기록

- Windows 10 x64에서 Codex와 Claude Code가 모의 모드의 MCP에 연결되는지 확인했습니다. GitHub의 Windows 러너에서는 Codex의 Decisions 모드 MCP 연결이 실패했습니다. [PR #202](https://github.com/abruption/aptly/pull/202)
- Windows 데스크톱의 로그인 세션에서는 Codex가 Decisions 모드의 MCP에 연결됐고, Windows 자격 증명 관리자에서 API 키를 읽어 승인된 Hook을 실행했습니다. 실제 시험에서는 네트워크 오류가 발생해 Decisions 응답을 확인하지 못했고, 서브에이전트는 시작되지 않았습니다. [PR #204](https://github.com/abruption/aptly/pull/204)

## 업데이트

전역으로 설치한 Aptly를 업데이트하려면 관련 호스트·MCP 서버·CLI 프로세스를 중지한 뒤 다음 명령을 실행하십시오.

```sh
aptly update
aptly setup --client all
```

호스트를 재시작하십시오. stable 실행기를 사용한다면 [보존 사본](../guide/ko/configuration.md#guide-stable-launcher)도 갱신하십시오. 자세한 내용은 [설치·업데이트 안내](../guide/ko/installation.md#guide-package-updates)를 참고하십시오.
