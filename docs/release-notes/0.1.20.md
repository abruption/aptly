# Aptly 0.1.20

## 변경 사항

- 한국어·영어·일본어·중국어 간체 가이드의 설치, 자동 추천, 통계 설명을 다듬었습니다. 필요한 조건과 실행할 명령을 쉽게 찾을 수 있도록 문단을 나누고, 현재 읽는 언어를 같은 방식으로 표시합니다.
- 예산 안내에서 Decisions API 호출에 비용이 발생할 수 있는 시점을 설명하고, 로컬 요청 기록 파일에 어떤 정보가 저장되는지 명확히 했습니다. 일부 이전 버전의 릴리즈 노트에는 빠진 npm·소스 링크를 보완했습니다. [이슈 #199](https://github.com/abruption/aptly/issues/199) · [PR #200](https://github.com/abruption/aptly/pull/200)

## 업데이트

관련 호스트·MCP 서버·CLI 프로세스를 중지한 뒤 전역 설치에서 실행하십시오.

```sh
aptly update
aptly setup --client all
```

호스트를 재시작하십시오. stable 실행기를 사용한다면 [보존 사본도 갱신](../guide/ko/configuration.md#guide-stable-launcher)하십시오. 자세한 내용은 [설치·업데이트 안내](../guide/ko/installation.md#guide-package-updates)를 참고하십시오.
