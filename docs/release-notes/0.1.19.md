# Aptly 0.1.19

## 변경 사항

- Codex 후보에 `gpt-6.2-sol`이 있으면 OpenAI Decisions API가 한 요청에서 `codex-deep` / `medium`과 `codex-deep-high` / `high` 중 작업에 맞는 조합을 고를 수 있습니다. 일반 심층 작업에는 medium을 우선하고, 상세한 의존성 분석이나 복합 실패 조건에 추가 추론이 필요하면 high를 고려하도록 안내합니다. [이슈 #193](https://github.com/abruption/aptly/issues/193) · [PR #194](https://github.com/abruption/aptly/pull/194)
- 자동 Hook은 호환되는 호출의 미지정 인자만 채웁니다. 본문이 불투명해 작업명만 전달할 때는 Sol/high를 제외합니다. 맥락 보충이 요청된 경우, 충분한 설명이 들어오면 명시한 값과 호환되는 high 후보를 다시 평가할 수 있습니다.
- 기존 후보 목록의 모델명과 순서는 유지됩니다. `gpt-6.2-sol`이 포함된 목록에서는 새 high 프로필도 후보가 됩니다. 이전 추천 기록은 계속 읽을 수 있으며, 카탈로그가 바뀌면 이전 요청 ID로 분류를 다시 호출하지 않습니다.

## 업데이트

관련 호스트·MCP 서버·CLI 프로세스를 중지한 뒤 전역 설치에서 실행하십시오.

```sh
aptly update
aptly setup --client all
```

호스트를 재시작하십시오. stable 실행기를 사용한다면 [보존 사본도 갱신](../guide/ko/configuration.md#guide-stable-launcher)하십시오. 자세한 내용은 [설치·업데이트 안내](../guide/ko/installation.md#guide-package-updates)를 참고하십시오.

## 검증

실제 Decisions로 사전에 분류한 합성 작업 12건을 시험했습니다. `gpt-6.2-sol / high` 4건, `gpt-6.2-sol / medium` 4건, 단순·일반 작업 4건이 모두 기대와 일치했습니다. Codex CLI 0.171.0에서는 테스트 도구로 작업 설명을 등록한 뒤 새 독립 호출 2건에 Hook이 각각 high와 medium을 채웠으며, 자식 실행 기록에서 해당 모델·effort와 완료를 확인했습니다. 이 결과는 이력 상속 호출의 적용이나 결과물 품질·비용 비교를 포함하지 않습니다.
