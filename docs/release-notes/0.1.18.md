# Aptly 0.1.18

## 변경 사항

- `codex-deep`의 기본 모델을 `gpt-6.2-sol`로 변경했습니다. 추론 강도는 `medium`입니다. 새 기본값은 Codex 후보 목록을 설정하지 않았거나 `aptly set default`로 처음 추가할 때 적용됩니다. [이슈 #186](https://github.com/abruption/aptly/issues/186) · [PR #187](https://github.com/abruption/aptly/pull/187)
- 기존 후보 목록은 유지됩니다. 목록에 `gpt-6.1-sol`이 있으면 `codex-deep-legacy` / `medium`으로 사용할 수 있습니다. 프로필 ID를 직접 전달하는 경우 현재 후보 ID를 `aptly capabilities`에서 확인하십시오. 이전 추천 기록은 계속 읽을 수 있으며, 카탈로그가 바뀌면 이전 요청 ID로 분류를 다시 실행하지 않습니다.
- 공식 모델 설명 갱신에 `gpt-6.2-sol`을 추가했습니다. 기존 설명 캐시도 사용할 수 있습니다.

## 업데이트

관련 호스트·MCP 서버·CLI 프로세스를 중지한 뒤 전역 설치에서 실행하십시오.

```sh
aptly update
aptly setup --client all
```

호스트를 재시작하십시오. stable 실행기를 사용한다면 [보존 사본도 갱신](../guide/ko/configuration.md#guide-stable-launcher)하십시오. [설치·업데이트 안내](../guide/ko/installation.md#guide-package-updates)를 참고하십시오.
