Published to npm on 2026-11-05. These GitHub Release notes were added retrospectively from the existing `v0.1.1` tag and actual publication results.

## Highlights

- Configure default environments and candidate models for Claude Code and Codex with `aptly set default` and hidden-input `aptly set env ENV_KEY`.
- Store classification API keys separately for each host in macOS Keychain, Windows Credential Manager, or Linux Secret Service (`secret-tool`), then load them at MCP startup. Configuration files contain references only.
- When the classification key is known to be missing locally, no API call or cost reservation begins. Failures where transmission may already have started retain unknown outcomes and existing reservations.
- Added CI checks for the compiled CLI and MCP from an installed npm archive. Installation tests that run lifecycle scripts use a separate runner from release packaging.

## Upgrade and compatibility

- Existing launch commands, environments, and policies are not overwritten automatically. OS key references require a standard launch path compatible with the current installation; custom wrappers, older versions, and other installation paths may be rejected.
- Failed key configuration attempts restore and verify the previous stored value where possible. Files and the OS credential store do not form a fully atomic transaction.
- Windows synthetic credential-store, isolated configuration, and installed-package checks passed. Native Claude Code or Codex sessions on Windows were not verified.
