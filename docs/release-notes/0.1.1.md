npm 게시일은 2026-11-05입니다. 이 GitHub Release 노트는 기존 `v0.1.1` 태그와 실제 게시 결과를 기준으로 사후 정리했습니다.

## 주요 변경

- `aptly set default`와 숨김 입력을 사용하는 `aptly set env ENV_KEY`로 Claude Code·Codex의 기본 환경과 후보 모델을 설정할 수 있습니다.
- 분류 API 키를 호스트별로 macOS Keychain·Windows Credential Manager·Linux Secret Service(`secret-tool`)에 저장하고 MCP 시작 시 읽습니다. 설정 파일에는 참조만 기록합니다.
- 로컬에서 분류 키가 없음을 확인하면 API 호출과 비용 예약을 시작하지 않습니다. 전송이 시작됐을 수 있는 실패는 기존 불명 결과·예약을 보존합니다.
- 설치된 npm archive의 compiled CLI·MCP를 시험하고, lifecycle script를 실행하는 설치 시험과 릴리즈 패키징을 서로 다른 runner로 분리했습니다.

## 업그레이드 및 호환성

- 기존 실행 명령·환경·정책을 자동으로 덮어쓰지 않습니다. OS 키 연결은 현재 설치와 호환되는 표준 실행 경로만 허용하며 사용자 지정 래퍼·구버전·다른 설치 위치는 거절할 수 있습니다.
- 키 설정 실패 시 이전 저장 값을 가능한 범위에서 복구하고 확인합니다. 파일과 OS 자격 저장소 사이의 완전한 원자적 트랜잭션을 보장하지 않습니다.
- Windows의 합성 자격 저장소·격리 설정·설치 패키지를 검증했으며, Windows의 실제 Claude Code·Codex 세션 실행을 인증한 것은 아닙니다.
