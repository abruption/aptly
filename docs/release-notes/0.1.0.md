First published to npm on 2026-11-05. These GitHub Release notes were added retrospectively from the existing `v0.1.0` tag.

## Highlights

- Initial public release of a local MCP server that recommends models and reasoning effort for Claude Code and Codex subagents through the OpenAI Decisions API.
- Three candidate tiers: Claude Haiku/Sonnet/Opus and Codex Luna(max)/Terra(high)/Sol(medium).
- JSON-array candidate configuration, explicit refresh and caching of official model descriptions, and bundled-description fallback.
- Direct recommendations through `recommend_agent` and the CLI, plus default selection through `PreToolUse`. Explicit model, effort, role, fork, and permission decisions are preserved.
- A JavaScript CLI built from TypeScript, local diagnostic reports, and a metadata ledger.

## Resolved issues

This is the first public release, so there is no list of fixes relative to an earlier public version. Fixes for issues created later are not attributed to this tag.

## Usage and compatibility

- Requires Node.js 24 or later. Each host controls MCP registration, native subagent execution, and permissions.
- Model access depends on the host and account. Successful installation or synthetic tests do not establish support for every host.
- Supply the classification API key through a secure execution environment. This version does not include the later `aptly set env` or OS credential-store configuration commands.

## Publication and validation scope

The first npm publication used local npm account authentication. This version has no GitHub Actions CI provenance. OIDC publication and verification results from 0.1.1 and later do not serve as evidence for this version.
