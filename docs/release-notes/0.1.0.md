npm 최초 게시일은 2026-11-05입니다. 이 GitHub Release 노트는 기존 `v0.1.0` 태그의 내용을 기준으로 사후 정리했습니다.

## 주요 변경

- Claude Code와 Codex 서브에이전트의 모델·reasoning effort를 OpenAI Decisions API로 추천하는 로컬 MCP를 공개했습니다.
- 기본 후보를 Claude Haiku·Sonnet·Opus와 Codex Luna(max)·Terra(high)·Sol(medium)의 세 단계로 구성했습니다.
- 후보 모델의 JSON 배열 설정, 공식 모델 설명의 명시적 갱신·캐시와 동봉 설명 fallback을 제공합니다.
- `recommend_agent`·CLI 직접 추천과 `PreToolUse` 기반 기본값 선택을 제공합니다. 명시적 모델·effort·역할·fork·권한 판단은 보존합니다.
- TypeScript 소스에서 빌드한 JavaScript CLI, 로컬 진단 보고서와 메타데이터 원장을 배포합니다.

## 해결한 이슈

최초 공개 릴리즈이므로 이전 공개 버전 대비 수정 이슈 목록은 없습니다. 이후 생성한 이슈의 수정 사항을 이 태그에 소급해 포함하지 않습니다.

## 사용 및 호환성

- Node.js 24 이상이 필요합니다. MCP 등록과 실제 서브에이전트 실행·권한은 각 호스트가 담당합니다.
- 모델 접근 가능성은 호스트·계정에 따라 다릅니다. 패키지 설치나 합성 시험 성공이 모든 호스트의 지원을 뜻하지 않습니다.
- 분류 API 키는 안전한 실행 환경에서 전달하십시오. 이 버전에는 후속 버전의 `aptly set env`와 OS 자격 저장소 설정 명령이 없습니다.

## 배포와 검증 범위

최초 npm 게시에는 로컬 npm 계정 인증을 사용했습니다. 이 버전에는 GitHub Actions CI provenance가 첨부되지 않았습니다. 후속 0.1.1부터의 OIDC 게시·검증 결과를 이 버전의 근거로 사용하지 않습니다.
