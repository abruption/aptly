Published `aptly@0.1.2` through GitHub Actions OIDC on 2026-11-06, then verified the registry files and provenance.

## Highlights

- Diagnose launchers before entering or storing a key with `--check`, and explicitly migrate only standard registrations that match their ownership receipts. If initial diagnosis fails, the CLI leaves all selected hosts unchanged.
- Persistent ledger locks now use Node.js's built-in SQLite and OS-managed process-lifetime locking. After a process exits, new requests can resume while existing `unknown` records, reserved costs, and completed cache entries remain intact.
- Explicitly allowlist classification task fields and document transmission, opt-out controls, and filtering limits. This release does not change default sharing behavior or confidence thresholds.
- General installation instructions use `npm install -g aptly@latest`, and the subtitle identifies the OpenAI Decisions API.

## Before upgrading

1. **Stop every host, MCP server, and CLI process that can write to an existing persistent ledger, and upgrade all writers together.** Older writers cannot coexist with the new persistent SQLite `.lock` file.
2. The new lock file remains after a normal exit. Do not delete a valid gate or journal. Empty or unrecognized legacy locks are not recovered automatically; quarantine only a confirmed legacy lock while offline. Do not reset the JSON ledger, `unknown` records, costs, or completed cache. Fresh installations need no legacy-lock quarantine.
3. Diagnose launcher errors before entering the key again. Custom wrappers and modified ownership records remain rejected even during explicit migration; validation is not bypassed to adopt them.

```sh
aptly set env OPENAI_API_KEY --client claude --check
aptly setup --client claude --migrate-launcher --dry-run
```

See the [0.1.2 installation and migration guide](https://github.com/abruption/aptly/blob/v0.1.2/docs/guide/en.md#installation) for application requirements. Ledger locking requires a local filesystem supporting atomic hard links and SQLite locks, with one canonical ledger path.

## Publication and verification

The isolated install test, fresh-runner packaging, and OIDC publication all succeeded in [Actions run 42151554506 / attempt 1](https://github.com/abruption/aptly/actions/runs/42151554506/attempts/1). Before publication, 371 tests and platform CI passed. After publication, the new artifact and registry files matched, and npm signatures, the exact SLSA bundle, and certificate-bound source, tag, workflow, and run identities were verified.

Windows CI warms PowerShell and serializes test files while retaining real concurrent-process tests and the production ACL checks and time limits. Synthetic tests and publication verification do not establish model quality or support for every host environment. No operating ledger was migrated during this publication.
