## 전파와 검증 범위

registry의 새 버전·latest와 attestation은 즉시 같은 시점에 보이지 않았습니다. attestation endpoint의 초기 404를 보존하고 7번째 조회에서 200을 확인한 뒤 서명 검증을 수행했습니다. 같은 소스·태그·run/attempt를 대상으로 읽기 전용으로 기다렸고 태그·게시 job을 반복하지 않았습니다. 이번 검증에는 별도의 실패한 npm 설치·서명 재시도가 없었습니다.

검증용 임시 설치·artifact 폴더는 정리했습니다. 전역 설치·운영 원장·호스트 설정·키·배포 보호 규칙을 변경하지 않았습니다. 새 confidence 평가나 native 자식 시험도 수행하지 않았습니다. 설치/연결 시험, 실제 게시 출처 검증과 자식 작업 품질은 구분합니다.
