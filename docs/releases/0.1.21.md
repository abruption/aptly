# 0.1.21 게시 기록

- 소스 커밋 `43a646b325b70f0091fe9f27aba5ef964f2b4eac`, 태그 `v0.1.21`.
- 병합 커밋의 [CI](https://github.com/abruption/aptly/actions/runs/44988949276) 7개, [의존성 감사](https://github.com/abruption/aptly/actions/runs/44988949282) 2개, [비밀 검사](https://github.com/abruption/aptly/actions/runs/44988949343) 1개가 통과했습니다.
- [GitHub Actions OIDC 게시](https://github.com/abruption/aptly/actions/runs/44989183588/attempts/1)의 작업 3개가 모두 성공했습니다. 확인 시점의 npm `latest`는 0.1.21입니다.
- 아카이브 SHA-256 `c41ae290e3b1703ae53d95b3d4dcc2508ad9b1714bf52a3f838dcadbed610629`.
- npm SHA-512 무결성 값 `sha512-eGYK8498YiQVNe5jrt3xi1KB2J0r7sGZKbJLY9WG066Hd9zyE9pWGYZc0zDxt8sxZs7twMNJaLZtCmVVRAMUlw==`.

npm 배포 파일은 Actions에서 검증한 아카이브와 일치했습니다. 격리 환경에 설치해 CLI 버전을 확인하고 npm 서명과 SLSA v1 출처 증명(provenance)을 검증했습니다. 증명에 포함된 저장소, 소스 SHA, 태그, 워크플로, 실행 번호, 시도 번호, 러너 정보가 실제 게시 실행과 일치했습니다.

게시 직후 표준 npm 다운로드 주소에서 캐시된 HTTP 404 응답을 확인했습니다. 캐시가 갱신된 뒤 같은 주소에서 파일을 내려받아 검증했습니다. 게시 작업은 한 번만 실행했습니다.

릴리즈 준비는 [이슈 #213](https://github.com/abruption/aptly/issues/213)과 [PR #214](https://github.com/abruption/aptly/pull/214)에 기록했습니다. 준비 단계의 로컬 테스트에서는 871개가 통과했고 16개를 건너뛰었습니다. 이번 게시 검증에서는 Decisions API를 호출하지 않았습니다.
