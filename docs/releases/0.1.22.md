npm 배포 파일이 Actions에서 검증한 아카이브와 일치했습니다. 격리 환경에서 CLI 버전을 확인하고, npm 서명과 SLSA v1 출처 증명(provenance)을 검증했습니다. 증명에 포함된 저장소, 소스 커밋, 태그, 워크플로, 실행 번호, 시도 번호와 러너 정보가 실제 게시 실행과 일치했습니다.

첫 격리 설치에서는 `ETARGET`이 발생했습니다. 설치용 메타데이터에 0.1.22가 표시된 뒤 같은 버전의 격리 설치와 출처 증명 검증을 완료했습니다.

릴리즈 준비는 [이슈 #221](https://github.com/abruption/aptly/issues/221)과 [PR #222](https://github.com/abruption/aptly/pull/222)에 기록했습니다. 준비 과정에서 로컬 테스트 891개와 설치 패키지 검사를 통과했습니다. 전역 설치 경로를 옮긴 뒤 관리형 npx의 Codex·Claude Code MCP가 모의 추천에 응답하는 것도 확인했습니다.
