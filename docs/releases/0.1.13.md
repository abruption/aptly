## 변경과 검증 범위

모델 후보 상속, 조회 상태·종료 코드, 통계 DB 명시적 활성화와 설정 유실 처리, 출시 안내, 원장 사전 확인의 읽기 전용 전환, doctor 및 프로세스 진단을 포함합니다. 준비 후보의 793개 테스트와 빌드·문서·공개 패키지·설치 tarball·fixture MCP/cache 검증이 통과했습니다. 게시 workflow는 태그의 소스를 새 runner에서 다시 검증하고 정확한 artifact만 OIDC로 게시했습니다.

게시 검증은 실제 계정 모델 접근·사용자 수용·품질·비용 절감이나 호스트 전체 설정 인증을 뜻하지 않습니다. 기존 호스트·전역 설치·키·전송 선택·Hook 신뢰·정책·원장·통계 이력은 변경하지 않았습니다. 검증 설치의 lifecycle script는 비활성화했고 임시 설치·artifact 다운로드 디렉터리를 정리했습니다.

사용자가 별도로 요청한 정리는 서브에이전트가 최신 main에 완전히 병합된 원격 브랜치 25개만 삭제했습니다. 매 삭제 직전 끝 커밋 불변·main 조상 관계·보호 상태·열린 PR head/base 미참조를 확인했습니다. main·활성 작업·로컬 브랜치·worktree·태그·저장소 설정은 보존했습니다.
