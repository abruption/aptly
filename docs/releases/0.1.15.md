## 변경과 검증 범위

Codex 기본 홈의 `CODEX_HOME` 누락 시 MCP 시작 오류를 수정합니다. 명시한 계정 홈이 우선하며 잘못된 명시 값은 계속 거절합니다. 사용자 지정 계정을 자동 탐색하지 않습니다. PR #161의 로컬 회귀 843개 중 827개 통과·실패 0개·임시 볼륨 권한 조건으로 16개 제외를 기록했고, 버전 준비에서 관련 테스트 40개와 타입·문서·패키지 검사를 통과했습니다. 원격 CI와 게시 runner는 정확한 병합/태그 소스를 별도로 검증했습니다.

새 기본 홈 stdio 회귀는 수정 전 0.1.14에서 실패하고 수정 후 통과했습니다. Claude Opus 5.5의 유효한 독립 검토와 Rebut Astra의 `invalid_output` 응답을 구분하며 후자는 유효 리뷰에 포함하지 않습니다. 게시 출처 검증은 실제 계정의 모델 접근·유료 Decisions 호출·native 자식 실행·사용자 수용·품질·비용 절감의 증거가 아닙니다. 격리 검증 설치의 lifecycle script를 비활성화했고 임시 설치·artifact 다운로드 디렉터리를 정리했습니다.

## 별도 승인한 Mac 업데이트

두 Mac에 registry 0.1.15를 기존 전역 prefix로 설치하고 등록된 실행 경로를 확인했습니다. 기존 설정·정책·Hook·소유권·원장·통계와 키 참조를 보존했습니다. 맥미니 첫 설치는 npm의 캐시된 메타데이터로 ETARGET를 반환했고 설치본 0.1.14와 cache hit를 확인한 뒤 `--prefer-online`으로 설치를 완료했습니다. npm 재게시나 키 재입력은 하지 않았습니다.

기본 Codex의 새 fixture MCP를 `CODEX_HOME` 없이 시작해 0.1.15 응답과 전송 범위를 확인했습니다. 맥북의 기존 선택 계정은 명시적 홈으로 별도 확인했습니다. 조회·관찰자 검증도 통과했습니다. OS 자격 저장소 조회·유료 분류·native 자식 실행·stable 전환·신뢰 자동 승인은 하지 않았으며, 기존 호스트 세션의 재로딩은 미관측이므로 재시작이 필요합니다.
