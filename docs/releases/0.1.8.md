## 전파와 검증 범위

registry 버전·latest와 attestation은 즉시 같은 시점에 보이지 않았습니다. attestation 초기 404를 보존하고 7번째 조회에서 200을 확인한 뒤 서명 검증을 수행했습니다. 같은 소스·태그·run/attempt를 대상으로 읽기 전용으로 기다렸으며 태그·게시 job을 반복하지 않았습니다. 이번 게시 후 검증에서는 실패한 npm 설치나 서명 재시도가 없었습니다.

검증용 임시 artifact/설치 폴더를 정리했습니다. 전역 설치·실제 호스트 설정·키·원장·예산·배포 보호 규칙을 변경하지 않았습니다. 새 제품 유료/native 평가도 수행하지 않았습니다. 0.1.8의 로컬 예약은 실제 청구 상한이 아니고, CLI 버전과 등록된 MCP의 실제 실행 버전은 별개입니다.
