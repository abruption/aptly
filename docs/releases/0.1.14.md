## 변경과 검증 범위

선택형 POSIX stable 실행기와 안전한 명시적 마이그레이션, 읽기 전용 진단, 관찰자 표준 입력 보존을 포함합니다. 준비 후보의 로컬 회귀 840개 중 824개 통과·실패 0개·임시 볼륨 권한 조건으로 16개 제외를 기록했습니다. 원격 Node 24·26 macOS·Ubuntu 시험은 별도로 실제 패키지 실행을 확인했습니다. 게시 runner는 태그 소스를 새로 검증했습니다.

게시 검증은 실제 계정의 모델 접근·품질·비용 절감·native 자식 실행을 뜻하지 않습니다. 격리 검증의 lifecycle script를 비활성화했고 임시 설치와 artifact 다운로드 디렉터리를 정리했습니다. 사용자가 별도로 승인한 두 Mac 업데이트와 실행 중 호스트의 재로딩은 게시 출처 검증과 구분합니다.

## 별도 승인한 Mac 업데이트

두 Mac에서 registry 0.1.14를 기존 전역 prefix에 lifecycle script 없이 설치했습니다. 각 Mac의 기존 Codex·Claude 등록 경로는 같은 새 패키지를 참조하며, 읽기 전용 조회와 무해한 관찰자 입력, 새 fixture MCP의 버전·전송 범위 검증을 통과했습니다. 설정·정책·Hook·소유권 기록·원장·통계 DB와 키 메타데이터를 보존했습니다. 이전 선택 계정의 부재·미등록은 자동 복원하지 않았습니다.

stable 실행기로 전환하거나 자격 저장소를 읽거나 신뢰를 자동 승인하지 않았습니다. fixture 검증은 유료 API·native 자식 실행 검증이 아니며, 기존 호스트의 재로딩은 미관측이므로 재시작이 필요합니다.
