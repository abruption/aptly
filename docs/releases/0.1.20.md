Actions 아티팩트와 npm 아카이브가 일치했습니다. 격리 설치에서 CLI 버전을 확인하고 npm 서명과 SLSA v1 출처 증명(provenance)을 검증했습니다. 증명에 기록된 저장소, 소스 SHA, 태그, 워크플로, 실행 ID와 시도 번호, GitHub 호스팅 실행기 정보가 실제 게시 실행과 일치했습니다.

게시 직후 표준 다운로드 주소에서 캐시된 HTTP 404 응답을 확인했습니다. 캐시가 갱신된 뒤 같은 버전의 표준 주소로 파일을 내려받아 검증했습니다. 게시 작업은 한 번만 실행했습니다.

다국어 문서 변경은 #199·PR #200, Windows에서 확인한 범위와 남은 한계는 PR #202·#204, 릴리즈 준비는 #205·PR #206에서 확인할 수 있습니다. 준비 단계 로컬 테스트에서 863개가 통과했고 실패는 없었습니다. 임시 볼륨 조건으로 16개는 제외했습니다. 패키지 격리 설치와 stable 실행기 검사는 통과했습니다.
