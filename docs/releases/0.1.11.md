## 조사와 검증

Orca 소스와 설치본 1.4.256에서 기본 홈의 같은 이름 MCP 등록을 관리형 홈에 동기화하고 계정 로컬 MCP 환경 변경을 정본에 승격하지 않는 경로를 확인했습니다. 당시 파일을 쓴 정확한 프로세스는 추적하지 않았습니다. 호스트 내부 패치는 포함하지 않습니다.

수정 후보의 전체 테스트 665개와 문서·빌드·공개 범위 검사, fixture MCP/cache·설치 tarball 검사를 통과했습니다. 별도 에이전트 검토가 발견한 전달 설정 복원 누락은 회귀 테스트로 보완하고 재확인했습니다. 맥미니 로컬과 맥북 SSH의 격리 설치에서 서로 다른 전송 범위의 두 합성 계정에 정본 MCP 테이블 동기화를 세 번 반복해 정책 바이트 보존·통계 조회·누락 홈 거부를 확인했습니다. 임시물은 정리했으며 이 시험의 유료 API 호출과 native 자식 실행은 0입니다.

SSH 시험은 처음에 원격 PATH에서 Node를 찾지 못해 결과가 없었습니다. 이를 성공으로 처리하지 않고 등록된 Node 경로를 사용해 재실행한 뒤 결과를 확인했습니다. 실제 사용자 설정·키·원장·통계 이력·신뢰를 변경하지 않았습니다. 이 결과를 실행 중 MCP의 갱신·실제 모델 수용·비용 절감 증거로 해석하지 않습니다.

버전 갱신 후 후보 검증 결과는 준비 PR 본문에 기록합니다. 최종 병합 main의 검사와 실제 게시 검증은 후속으로 기록해야 합니다.
