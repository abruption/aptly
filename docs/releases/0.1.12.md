## 수정과 검증

CLI는 CODEX_HOME이 없을 때 자신이 선택한 표준 홈을 검증에 사용합니다. 명시적 계정 홈을 보존하고 빈 값·상대 경로·제어문자를 거부합니다. MCP 시작 시 전달이 누락됐을 때 다른 홈으로 추정하지 않고 중단하는 검사는 유지합니다. 668개 테스트, 빌드·문서·공개 범위 검사(소스 349개/패키지 134개), fixture MCP/cache 및 격리 설치 tarball 시험을 통과했습니다.

두 Mac의 등록 npm 서버를 실제 0.1.12로 갱신했고, 기본/정본과 선택 계정의 정책 바이트·전송 선택·Hook·통계 설정과 소유권·원장 참조/바이트를 보존했습니다. 게시된 compiled CLI로 CODEX_HOME 없는 기본 홈의 읽기 전용 점검·일반 setup·통계 조회 성공을 확인했습니다. 전송 확인 질문을 대신 답하거나 동의를 변경하지 않았습니다.

새 MCP 프로세스의 버전과 기존 전송 범위는 확인했지만 기존 호스트 세션의 재로딩은 관측하지 않았습니다. 유료 API 호출·native 자식 실행, 실제 모델/effort·사용자 수용·품질·비용 절감이나 전체 호스트 설정 인증의 근거가 아닙니다. 임시 설치는 정리했고 키·신뢰를 복사하거나 통계 이력을 초기화하지 않았습니다.
