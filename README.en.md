# Aptly

[한국어](README.md) · **English** · [简体中文](README.zh-CN.md) · [日本語](README.ja.md)

**A local MCP server that selects Claude Code and Codex subagent models and reasoning effort to suit the task.**

Aptly classifies a minimal task summary with the OpenAI Decisions API and recommends an allowlisted execution profile. Its installed Hook can automatically select defaults for fresh, general-purpose subagents without explicit choices. The host retains control of execution and permissions.

## Quick start

Use Node.js **24 or later** and Claude Code or Codex. This is an **MIT-licensed local 0.1.0 package draft**, not a release published to the npm registry. Replace the archive path below with the actual reviewed archive.

```sh
npm install --prefix ./aptly-local /absolute/path/aptly-0.1.0.tgz
./aptly-local/node_modules/.bin/aptly setup --client all --mode defaults
```

During installation, `postinstall` registers the MCP server and a `PreToolUse` Hook in existing host configuration directories. Run `setup` explicitly if automatic registration was skipped or a host has no configuration directory yet. Other settings and Hooks, and any existing Aptly launch command and environment, are preserved.

Pass the classification key, `OPENAI_API_KEY`, to the MCP process through a secure execution environment. Do not put it in command arguments, requests, configuration JSON, or the repository. Restart the host or MCP server, then **review and trust the new Hook through `/hooks` in Codex**. See [installation, keys, and registration](docs/guide/en.md#installation).

## Usage modes

| Mode | Behavior |
|---|---|
| Automatic Hook | Selects defaults for fresh, general-purpose calls without an explicit model, effort, fixed role, inherited history, or resume target |
| Direct recommendation | Returns a profile through `recommend_agent` or `aptly recommend`; review it and decide separately whether to run it in the host |
| fixture | Tests recommendations generated by local rules without a key or network access; these are not actual Decisions results |

Automatic selection targets Codex calls with `fork_turns: "none"` and Claude Code calls with `subagent_type: "general-purpose"`. Explicit choices, insufficient context, and authentication or connection errors leave the original call unchanged. A recommendation does not verify model access or the host's complete configuration.
